--- src/app/ — 应用入口层 ---------------------------------------------------

  src/app/main.c
    用途：程序主入口。初始化 LVGL 核心（lv_init）、显示设备（framebuffer
          800×480）、输入设备（evdev），调用 create_ui() 创建界面，然后
          启动 5 个后台 pthread 线程（TCP 客户端、温湿度采集、数据写文件、
          LED 控制、蜂鸣器控制），创建 200ms lv_timer 消费 pending event
          队列，最后进入主循环（lv_tick_inc + lv_timer_handler，5ms 间隔）。
          另含 custom_tick_get() 函数使用 gettimeofday 获取真实毫秒时间。

  src/app/ui_manager.h
    用途：UI 管理器头文件。声明 create_ui() 函数——创建整个界面（顶部
          导航栏 + 4 个页面容器，默认显示主页，同时初始化锁与时间标签）。

  src/app/ui_manager.c
    用途：UI 框架实现。创建顶部导航栏（50px 高，深蓝底色）和 4 个页面
          容器（800×430），初始化所有读写锁、互斥锁、条件变量，创建
          1 秒刷新时间标签的 lv_timer 和 2 秒刷新主页数据的 lv_timer。
          提供 switch_page() 页面切换功能。

--- src/ui/ — UI 界面层（页面与公共组件） -----------------------------------

  src/ui/ui_common.h
    用途：项目核心头文件（"宪法"）。定义页面 ID 枚举、颜色方案宏、字体
          宏、布局常量（屏幕 800×480、导航栏 50px 等）、所有共享状态变量
          extern 声明（温湿度、阈值、设备状态、锁、条件变量）、UI 控件
          句柄 extern 声明、跨线程安全更新接口（push_pending_event /
          process_pending_events / request_threshold_refresh /
          request_history_refresh）。

  src/ui/ui_common.c
    用途：共享状态与跨线程机制实现。定义全部全局变量（温湿度、阈值、
          状态、锁、条件变量）并初始化，实现 pending event 队列（16 条
          环形缓冲，mutex 保护），主线程 200ms lv_timer 消费队列更新事件
          页与阈值显示，提供 create_data_card() / make_card() 卡片工厂函数。

  src/ui/ui_navbar.h
    用途：导航栏头文件。声明 create_top_bar()（创建顶部导航栏）和
          switch_page()（切换到指定页面）。

  src/ui/ui_navbar.c
    用途：导航栏实现。创建 50px 高顶部栏，左侧标题"embedded system"，
          右侧 4 个页面切换按钮（Home/Event/History/Settings），点击切换
          页面并高亮当前按钮（切换 LV_OBJ_FLAG_HIDDEN 标志）。

  src/ui/ui_page_home.h
    用途：主页头文件。声明 create_home_page()（创建主页）、
          update_home_data()（更新温湿度显示）、mock_data_update()
          （lv_timer 2 秒定时刷新主页数据与曲线）。

  src/ui/ui_page_home.c
    用途：主页实现。左侧温度/湿度数据卡片（大号数值显示，超阈值红色/
          正常绿色），右侧 lv_chart 折线图（30 数据点，温度 0-50 / 湿度
          0-100 双 Y 轴）。每 2 秒读取共享温湿度更新显示并推入曲线新点。

  src/ui/ui_page_event.h
    用途：事件页头文件。声明 create_event_page()（创建事件页）、
          update_event_page()（追加事件到表格）、update_system_status()
          （更新系统状态卡片）。

  src/ui/ui_page_event.c
    用途：事件页实现。左侧 30 行事件表格（记录告警/命令/系统事件），
          右侧 3 个统计卡片（alarm/command/system 计数），新事件在顶部
          插入。

  src/ui/ui_page_history.h
    用途：历史页头文件。声明 create_history_page()（创建历史页）、
          write_history_data()（从 data.txt 读取最近 20 条填表）、
          update_history_card()（更新历史数据卡片）。

  src/ui/ui_page_history.c
    用途：历史页实现。创建时从 ./data.txt 读取最近 20 条历史记录
          （时间,温度,湿度格式），使用环形缓冲算法处理超 20 条情况。
          后续新数据通过 pending event 机制由主线程 200ms 定时器检测
          标志位后更新表格，最新数据在第一行。

  src/ui/ui_page_settings.h
    用途：设置页头文件。声明 create_settings_page()（创建设置页）、
          write_config() / read_config()（配置读写 config.txt）、
          write_threshold_config() / display_threshold()（阈值读写
          threshold.txt），声明 temp_threshold / humi_threshold / cfg_saved
          全局变量。

  src/ui/ui_page_settings.c
    用途：设置页实现。显示 MQTT 配置信息（服务器地址、端口、设备 ID，
          默认华为云 IoT 平台配置），温度/湿度阈值调节按钮（步进 0.5），
          LED 和蜂鸣器开关控件，配置保存与重置按钮。配置通过 fopen/
          fprintf/sscanf 读写 config.txt 和 threshold.txt 纯文本文件。

--- src/data/ — 数据层 -------------------------------------------------------

  src/data/data_source.h
    用途：数据源头文件。声明 get_temp_humi()（后台线程：HTTP 拉取天气
          数据写入共享变量）和 write_data_to_file()（后台线程：将温湿度
          数据持久化写入 data.txt）。

  src/data/data_source.c
    用途：数据采集与持久化实现。
          - get_temp_humi()：每 5 秒通过裸 socket 手动构造 HTTP GET 请求
            访问心知天气 API（api.seniverse.com），获取广州实时温湿度，
            用 cJSON 解析 JSON 响应，写入共享变量（读写锁保护），发送
            cond_var 信号唤醒持久化线程，请求历史页刷新。HTTP 请求在锁
            外执行避免阻塞。
          - write_data_to_file()：事件驱动模式，pthread_cond_wait 阻塞
            等待新数据信号，唤醒后格式化"时间,温度,湿度"写入 data.txt，
            跳过重复数据。

--- src/net/ — 网络层 --------------------------------------------------------

  src/net/network.h
    用途：网络层头文件。声明 client()（TCP 客户端主线程入口）和
          httprequest_weather()（HTTP 天气请求函数，返回 temp_humi_t 结构）。

  src/net/network.c
    用途：TCP 通信与 HTTP 天气请求实现。
          - client()：创建 TCP socket 连接服务器（192.168.44.21:8888），
            失败每 5 秒重试。连接成功后启动接收和发送两个子线程。
          - 接收线程(get_news)：循环 recv() 接收 JSON 命令，cJSON 解析
            command_name 和 paras，支持 LED 开关、蜂鸣器开关、温度阈值、
            湿度阈值四类远程指令，通过 status_mutex 加锁写入状态变量，
            发送条件变量信号唤醒 LED/BEEP 线程，push_pending_event 通知
            主线程更新 UI。
          - 发送线程(send_news)：每 5 秒读取温湿度、阈值和设备状态，
            cJSON 组装 JSON 上报包发送至服务器。
          - httprequest_weather()：DNS 解析 → TCP 连接 → HTTP GET 请求 →
            接收响应 → 解析 Content-Length → 接收 JSON 正文 → cJSON 解析
            提取温湿度，完整错误检查和资源释放。

--- src/drivers/ — 硬件驱动层 ------------------------------------------------

  src/drivers/hw_ctrl.h
    用途：硬件控制头文件。声明 led_ctrl()（LED 控制线程入口）和
          beep_ctrl()（蜂鸣器控制线程入口）。

  src/drivers/hw_ctrl.c
    用途：LED 与蜂鸣器硬件控制实现。
          - led_ctrl()：打开 /dev/Led 设备文件，通过 ioctl() 控制 4 路 LED。
            LED_status 为 OFF 时 pthread_cond_wait 阻塞睡眠（零 CPU 占用）；
            被唤醒后根据温度/阈值关系决策：达到阈值四灯常亮，未达阈值
            四灯同步闪烁，闪烁间隔随温度升高缩短（1s → 50ms）。
          - beep_ctrl()：打开 /dev/beep 设备文件。OFF 时条件变量阻塞；
            ON 时检查温度/湿度是否超阈值，超限时间歇告警（响 1s 停 1s），
            未超限时 sleep(1) 避免空循环。
